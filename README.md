# 🍳 AI Recipe Generator

AI Recipe Generator is a modern and responsive web application built using HTML, CSS, and JavaScript with Spoonacular API integration. The app allows users to search recipes by ingredients, view cooking instructions, ingredients list, cooking time, and watch recipe videos on YouTube. It also includes dark/light mode, favorite recipe management, popup recipe details, and a clean glassmorphism UI for an interactive user experience.

---

## ✨ Features

- 🔍 Search recipes instantly  
- 🍲 View ingredients and cooking instructions  
- ⏱ Check cooking time  
- ▶ Watch recipe videos on YouTube  
- ❤️ Add & remove favorite recipes  
- 🌙 Dark / Light mode toggle  
- 📱 Responsive modern UI  
- 🔥 Interactive recipe popup cards  

---

## 🛠 Technologies Used

- JavaScript  
- Spoonacular API
